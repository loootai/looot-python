# looot-python

## What this repo is

The official Python client for `https://api.looot.ai`. `Looot` (sync) and `AsyncLooot`
(asyncio) have the same methods. Methods map one to one to REST routes and return typed dicts
(`TypedDict`, open at runtime). One runtime dependency, `httpx`. Same surface as looot-js; keep
them aligned with the looot SDK contract.

## Layout

- `src/looot/_client.py`: `Looot`. The only file to edit for a method change.
- `src/looot/_async_client.py`: generated by `python scripts/gen_async.py`. Never edit by hand.
- `src/looot/_core.py`: request building, response reading, retry timing. No I/O.
- `src/looot/_errors.py`: `LoootError`, `TopUp`, the retryable table.
- `src/looot/_types.py`: response and option types.
- `src/looot/_version.py`: the version hatchling reads.

## Build and test

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.lock
.venv/bin/pip install --no-deps -e .
.venv/bin/pytest                      # offline, httpx.MockTransport and respx
.venv/bin/pytest -m live              # free public routes only; search only if LOOOT_TOKEN is set
.venv/bin/python scripts/gen_async.py --check
bash scripts/leak-scan.sh .
git config core.hooksPath .githooks
```

## Adding a method

1. Add it to `Looot` in `_client.py` with snake_case arguments and camelCase wire names.
2. Run `python scripts/gen_async.py`.
3. Add a row to `CASES` in `tests/test_client.py` and a line in the README method table.

## Dependencies

Exact pins in `requirements-dev.lock`. The runtime range for users is in `pyproject.toml`.
`pin-guard/verify.py` covers npm only, so for a Python package check the release on
`https://pypi.org/pypi/<name>/<version>/json`: skip a version younger than 7 days, a yanked
one, or one from a new maintainer. Regenerate the lock with `pip freeze` after any change.

## Release

Only after the owner says yes. Follow `PUBLISH.md`: bump `_version.py` and `CHANGELOG.md`,
push a `vX.Y.Z` tag, and the release workflow uploads through PyPI trusted publishing.

## Public looot surface this repo may link

`https://docs.looot.ai` (and `/reference`), `https://looot.ai/skill.md`, the REST routes under
`https://api.looot.ai/v1/`, the MCP server at `https://api.looot.ai/mcp`. Never link the
gateway's OpenAPI JSON from a README, a package page or a doc.

## Never

- Copy code or text from the private gateway repo.
- Commit a token, key, `.env` file or any secret.
- Write internal hosts, local machine paths, workspace or customer ids, or personal emails.
- Name private repos or private branches.
- Call a paid route from a test.
